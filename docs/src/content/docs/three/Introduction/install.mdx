## Installing the Packages

Navara packages are published on npm under the [`@navaramap`](https://www.npmjs.com/org/navaramap) scope. Install `@navaramap/three` together with its peer dependencies `three` and `postprocessing`. Most apps also want `@navaramap/three_default_plugin`, which registers the built-in mesh, effect, and light Descriptors:

<Tabs syncKey="pkg">

<TabItem label="npm">

```bash
npm install @navaramap/three @navaramap/three_default_plugin three postprocessing
```

</TabItem>

<TabItem label="yarn">

```bash
yarn add @navaramap/three @navaramap/three_default_plugin three postprocessing
```

</TabItem>

<TabItem label="pnpm">

```bash
pnpm add @navaramap/three @navaramap/three_default_plugin three postprocessing
```

</TabItem>

</Tabs>
